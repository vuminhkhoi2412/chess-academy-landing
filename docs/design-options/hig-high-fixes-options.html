H4 · Chưa có đáp án cho chế độ tối, tương phản cao, giảm trong suốt

Trang hiện có 0 truy vấn prefers-color-scheme, prefers-contrast hay prefers-reduced-transparency. Thanh đầu trang và thanh liên hệ dưới đáy đều dùng backdrop-blur. Đề xuất chia ba bước độc lập, làm bước 1 và 2 trước, bước 3 khi sẵn sàng. Bật từng công tắc để xem; bản thật dùng media query nên chạy theo cài đặt của máy.

/* 1 · global.css – giảm trong suốt: header và thanh liên hệ thành nền đặc */
@media (prefers-reduced-transparency: reduce) {
  header.sticky, .gc-contact-bar { background: var(--color-cream); backdrop-filter: none; }
}
/* 2 · tương phản cao: chữ phụ đậm hơn, viền rõ hơn */
@media (prefers-contrast: more) {
  :root { --color-slate-500: var(--color-slate-700); --color-slate-600: var(--color-slate-800); }
  .border-slate-200 { border-color: var(--color-slate-500); }
}
/* 3 · tối: đổi token, thêm color-scheme (làm sau cùng, ảnh thật không đổi) */
:root { color-scheme: light dark; }
@media (prefers-color-scheme: dark) {
  @theme { --color-cream: #0e1b29; }  /* + surface, text, border theo bảng bên trên */
}

Ghi chú phạm vi: bước 3 đụng gần như mọi lớp bg-white, text-slate-* và border-slate-* trong Tailwind (khoảng 160 chỗ). Nên làm bằng token ngữ nghĩa (--surface, --text) chứ không thêm dark: từng chỗ.
